# CardRadioPlayer — Cardputer ADV 音乐 + 网络电台播放器

M5Stack Cardputer ADV 上的 MP3 播放器与中文网络电台，一套固件两种玩法：

- **音乐库**：播放 microSD 卡里的 MP3，文件夹浏览，3 段均衡器，随机 / 循环 / 快进快退，断点续听。
- **网络电台**：内置 **1037 个国内电台**（新闻、交通、音乐、经济、文艺、生活、方言等），支持**拼音搜索**、**最近收听 20 条**、多 WiFi 自动择优连接。

本项目基于 [TurbulentGoat/cardputer-adv-mp3-player](https://github.com/TurbulentGoat/cardputer-adv-mp3-player) 开发，在其本地 MP3 播放功能之上，使用 **WorkBuddy** 增加网络电台、电台搜索、多 WiFi 记忆等功能；界面风格、解码器与整体工程结构沿用上游。

## 功能特性

### 音乐库（本地）

- 全卡文件夹浏览，文件夹优先，文件名自然排序（`2` 在 `10` 之前）
- 选中曲目后顺序播放整个文件夹
- 随机播放，列表循环 / 单曲循环
- 快退 / 快进 10 秒，长按连续拖动
- 3 段均衡器（低 / 中 / 高），每段 ±12 dB，可单段归零或整体拉平
- 读取 ID3v2.2 / 2.3 / 2.4 / ID3v1 标签（标题、艺术家、专辑）
- CBR / VBR 均可准确显示时长与拖动
- 扬声器 / 耳机输出（插入 3.5 mm 自动切换，硬件静音扬声器）
- 记住上次播放的文件与位置，开机「接着听」
- 音量、EQ、随机、循环、亮度、上次文件夹均可掉电保存

### 网络电台

- **1037 个国内电台**，全部为 MP3 直连流（编译前逐台实测可播），不收录境外台
- 9 个分组：新闻资讯 204 / 音乐广播 154 / 交通汽车 247 / 经济财经 41 / 文艺曲艺 30 / 生活旅游 67 / 体育运动 3 / 方言民族 20 / 综合其他 271
- 分组按**台名关键词**归类（交通、经济、新闻、体育、音乐、文艺、生活、方言），无法判断的进「综合其他」
- **拼音搜索**：支持台名、全拼、拼音首字母三种匹配，边打边出结果
  - `zgz` → 中国之声
  - `jiaotong` → 各地交通广播
  - `fm97` → 台名里带 FM97 的电台
- **最近收听 20 条**，新的置顶、自动去重、掉电不丢
- WiFi 记忆最多 **20 个网络**：开机扫描，按信号强度自动连最强的已存网络，其余作为后备；换到公司 / 手机热点无需重新输入密码
- 断流自动重连，连接失败按指数退避重试，不卡界面

### 系统
- **定时关闭（睡眠定时器）**：按 `T` 选择 15–150 分钟，到期停止播放、断开 WiFi 并深度睡眠（约 2–5 mA），按 G0 键唤醒

- 不依赖 PSRAM（Cardputer ADV 为 ESP32-S3FN8，8 MB Flash、无 PSRAM），所有缓冲都在内部 RAM 内精心分配
- 状态页（`I`）实时显示内部剩余内存、最低水位、最大连续块、显示 / 解码 / 取流缓冲位置、WiFi 与运行时长
- 播放中 1 分钟无操作自动熄屏省电，任意键唤醒
- 4 档亮度（约 16% / 39% / 71% / 100%）

## 硬件要求

- M5Stack Cardputer ADV（StampS3A，ESP32-S3FN8，ES8311 音频编解码，TCA8418 键盘控制器）
- microSD 卡，FAT32 或 exFAT

> 上游库同样支持初代 Cardputer，理论可运行，但本项目未在初代机器上验证。

## 刷机

发布页提供三个固件，按需要选一个：

| 文件 | 用途 | 烧录地址 |
|---|---|---|
| `cardradio-1.1-merged.bin` | **推荐**。完整镜像，含 bootloader + 分区表 + 应用 | `0x0` |
| `CardRadio-1.1.bin` | 仅应用分区，已有正确 bootloader 时使用 | `0x10000` |
| `cardradio-1.1.patch` | 与 app bin 相同，供 OTA / 增量工具使用 | — |

**esptool 命令行**（把 `COM5` 换成实际串口）：

```bash
esptool.py --chip esp32s3 -p COM5 -b 460800 write_flash 0x0 cardradio-1.1-merged.bin
```

**M5Stack 官方烧录工具 / 网页烧录器**：选择「ESP32-S3」，偏移 `0x0`，载入 `cardradio-1.1-merged.bin`，按提示让设备进入下载模式。

首次开机若提示「没有 microSD 卡」，插入 FAT32 / exFAT 卡后重新上电即可（播放本地音乐必需，只听网络电台也需要挂载成功才会进入主界面）。

## 使用说明

### 开机

1. 上电后显示启动画面，挂载 SD 卡（没有卡会一直提示，插卡即可）。
2. 自动读取已保存的 WiFi 并在后台连接，屏幕进入**主界面**。
3. 主界面两张卡片：**音乐库**、**网络电台**，`←/→` 或 `↑/↓` 切换，`ENT` 进入。

### 音乐库

1. 按 `L`，或在主界面选中「音乐库」后按 `ENT`，打开文件夹选择器。
2. `↑/↓` 移动，`ENT` 进入文件夹或直接播放该 MP3；`BKSP` 返回上一级。
3. 选中文件后自动顺序播放该文件夹内全部 MP3。
4. 播放页 `↑/↓` 调音量，`←/→` 快退 / 快进 10 秒（长按连续拖动），`ENT` 暂停。
5. `N` / `P` 切歌，`S` 随机，`R` 循环模式，`E` 均衡器。

### 网络电台

1. 按 `O`，或在主界面选中「网络电台」后按 `ENT`，进入电台菜单。
2. 菜单项：**最近收听**、**搜索电台**、**全部电台**、以及 9 个分组。
3. 选中电台按 `ENT` 开始收听，`N` / `P` 在当前列表内切台。
4. 未连 WiFi 时按 `W` 进入配网（见下文）。

### 搜索电台

- 电台菜单选「搜索电台」，**直接打字**即可（物理键盘就是输入法）。
- 支持台名、全拼、拼音首字母，输入行下方实时显示命中数与预览。
- `ENT` 进入完整结果列表；`BKSP` 删一个字（关键词为空时退出搜索）；`ESC` 关闭。
- 在结果列表里按 `BKSP` 会回到搜索页，关键词保留。

### WiFi 配网

- 任意界面按 `W` 打开 WiFi 列表（扫描约 2 秒）。
- `↑/↓` 选择网络，`ENT` 连接；已存网络自动带密码，新网络进入密码输入页。
- `X` 忘记选中的已存网络，`R` 重新扫描。
- 已存网络最多 **20 个**，开机自动挑信号最强的连接。

## 快捷键总表

设备上按 `H` 随时打开内置快捷键页，`H` / `ESC` 关闭。下表为完整说明。

### 全局（所有界面通用）

| 按键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `N` / `P` | 下一首 / 上一首（电台模式下为下一个 / 上一个台） |
| `=` / `-` | 音量 +5% / -5%（长按连发） |
| `M` | 静音开关 |
| `S` | 随机播放开关 |
| `R` | 循环模式：不循环 → 列表循环 → 单曲循环（WiFi 列表、文件夹页除外） |
| `E` | 打开 / 关闭均衡器 |
| `L` | 打开音乐库（文件夹选择） |
| `O` | 打开网络电台菜单 |
| `TAB` | 主界面 ↔ 正在播放页 |
| `H` | 快捷键帮助页 |
| `I` | 运行状态页（内存 / WiFi / 运行时间） |
| `B` | 亮度切换（4 档） |
| `D` | 立即熄屏 |
| `T` | 定时关闭：选 15 / 30 / 45 / 60 / 90 / 120 / 150 分钟，到期自动停止播放、断开 WiFi 并进入深度睡眠（按侧键 G0 唤醒，唤醒后回到主界面） |
| `G0`（侧面按钮） | 播放 / 暂停，同时唤醒屏幕 |

### 主界面

| 按键 | 功能 |
|---|---|
| `←/→`、`↑/↓` | 切换「音乐库 / 网络电台」卡片 |
| `ENT` | 进入选中卡片 |
| `F` | 直接打开文件夹选择器 |
| `W` | 打开 WiFi 列表 |

### 正在播放（本地音乐）

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 音量 + / - |
| `←` / `→` | 快退 / 快进 10 秒（长按连续） |
| `ENT` | 播放 / 暂停 |
| `F` | 换一个文件夹播放 |
| `BKSP` / `ESC` | 返回主界面 |

### 文件夹选择器

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 上下移动（到头循环） |
| `←` / `→` | 翻页（每页 5 行） |
| `ENT` | 进入文件夹 / 播放文件 |
| `R` | 重新读取存储卡 |
| `BKSP` | 返回上一级目录 |
| `ESC` | 退出选择器 |

### 均衡器

| 按键 | 功能 |
|---|---|
| `←` / `→` | 选择频段（低 / 中 / 高） |
| `↑` / `↓` | 该频段 ±1 dB（范围 ±12 dB） |
| `0` | 当前频段归零 |
| `F` | 三段全部归零（平直） |
| `ENT` / `BKSP` / `ESC` | 退出 |

### 网络电台菜单

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 上下移动（到头循环） |
| `←` / `→` | 翻页（每页 5 项） |
| `ENT` | 进入（最近收听 / 搜索电台 / 全部电台 / 分组） |
| `W` | 打开 WiFi 列表 |
| `BKSP` / `ESC` | 返回主界面 |

### 电台列表

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 上下移动（到头循环） |
| `←` / `→` | 翻页（每页 5 行） |
| `ENT` | 收听选中电台 |
| `W` | 打开 WiFi 列表 |
| `BKSP` / `ESC` | 返回菜单（从搜索进来的则回搜索页，关键词保留） |

### 搜索电台

| 按键 | 功能 |
|---|---|
| 任意字符键 | 输入关键词（台名 / 全拼 / 首字母） |
| `ENT` | 查看完整结果列表 |
| `BKSP` | 删除一个字符（关键词为空时退出搜索） |
| `ESC` | 退出搜索 |

### WiFi 列表

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 选择网络 |
| `ENT` | 连接（已存网络自动带密码，新网络进入密码页） |
| `X` | 忘记选中的已存网络 |
| `R` | 重新扫描 |
| `BKSP` / `ESC` | 返回上一界面 |

### WiFi 密码输入

| 按键 | 功能 |
|---|---|

| `BKSP` | 删除一个字符 |
| `ESC` | 取消 |

主要源码：

```
src/
  main.cpp        界面、按键、状态机
  Player.cpp/.h   libmad 解码 + I2S 输出 + 网络取流调度
  RadioSource.cpp HTTP 直连流读取、ICY 元数据剥离、环形缓冲
  HlsSource.cpp   HLS(m3u8 / MPEG-TS) 支持（能力保留，当前电台表均为 MP3 直连）

  Stations.h      电台表（9 组，1037 台）
  StationsPinyin.h 自动生成的拼音索引
  Library.cpp/.h  SD 卡目录浏览与排序
  Mp3Info.cpp/.h  ID3 标签与时长解析
tools/
  gen_station_pinyin.py     电台拼音索引生成
  pio_m5gfx_font_trim.py    M5GFX 字库裁剪钩子
```
